系統使用說明

  • 起始頁面請輸入年齡 / 性別 / 檢傷時間 / 最後正常 / 發作時間
  • 紅色數字鐘為當下時間距離 Onset/LNT 時間
  • 若 < 3.5hr，啟動鈕呈現建議啟動 stroke code < 3.5hr
  • 若 3.5-24hr，會跳出 GFAST 頁面供填寫
  • 若有啟動 Stroke code / IA code 進入的頁面將呈現綠色數字鐘 (Time from Door 距離檢傷時間)
  • 若本院無取栓，至轉診頁面輸入欲轉至外院，主要決策者，生成格式 > 複製資訊
  • 病解頁面提供 tPA/EVT 相關資訊
  • 主畫面最下面可查詢新竹台大分院及桃竹苗區域聯防取栓班表
  • 主頁面依據流程可按時鐘鈕紀錄當下時間 (側頁⏰可補登時間)
側頁神內編輯臨床資訊:
  • NCCT/CTA 欄位有紀錄時間才會跳出欄位寫 finding
  • NIHSS 輸入數字可自動計算總分，插管可輸入 X
  • L't/R't MCA 可自動帶入預設 NE 範本及 NIHSS
  • 按「📝 生成格式」>「📋 複製內容」可轉貼至 Line / 照會單
編輯結束後，請記得按主頁面上傳鈕 💾
