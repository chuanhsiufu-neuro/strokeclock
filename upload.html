系統使用說明

  • 起始頁面請輸入發現異常 / (最後正常) / 檢傷時間，點選 code type / start 開始編輯
  • 綠色數字鐘為距離檢傷時間 / 紅色數字鐘為距離 Onset/LNT 時間
  • 主頁面依 CT / tPA / CTA / Puncture / 離部，可按時鐘鈕紀錄當下時間 (側頁時鐘可編輯時間)
側頁神內編輯臨床資訊:
  • stroke code 有點選才會跳出；神內抵達時間預設離 code 五分鐘
  • CT/CTA 欄位有紀錄時間才會跳出欄位寫 finding
  • NIHSS 輸入數字可自動計算總分，插管可輸入 X
  • L't/R't MCA 可自動生成預設 NE 範本及 NIHSS
  • 按「📝 生成格式」>「📋 複製內容」可轉貼至 Line / 照會單
  • 院內/轉診取栓班表已預設該時段排班人員在側頁神內及側頁轉診
  • 若本院無取栓，至轉診頁面輸入欲轉至的醫院，主要決策者，生成格式 > 複製資訊可將側頁神內的臨床資訊部分帶入轉診資訊，方便轉傳至外援取栓群組
  • 病解頁面提供 tPA / EVT 之相關資訊
編輯結束後，請記得按主頁面上傳鈕 ⬆️
